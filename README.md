# Bé học rồi xem TV

Ứng dụng Android TV với câu hỏi kiến thức lớp 6. Tải APK sau khi bản phát hành được xây dựng thành công tại [Releases](https://github.com/ngochieuspt/bexem/releases).

Đây là bản thử nghiệm cho Sony Android TV; quyền hiển thị đè và hoạt động nền còn cần kiểm tra trên thiết bị thật.
